n8n Backup rclone

Integrazione privata per il backup automatico di un'istanza self-hosted di n8n su Google Drive.

Funzionamento

L'applicazione utilizza rclone e la Google Drive API per caricare, verificare e gestire copie di backup cifrate tramite age.

L'accesso OAuth utilizza lo scope drive.file, limitato ai file creati o autorizzati per l'applicazione.

Utilizzo

Il progetto è destinato esclusivamente all'uso personale del proprietario dell'account. Non è un servizio commerciale né pubblico.
